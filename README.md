# 고동현 게임 클라이언트 웹 포트폴리오

## 구조
- index.html : 메인 포트폴리오
- full-portfolio.html : 31페이지 전체 웹 뷰어
- projects/samurai.html : 사무라이 키우기 상세
- projects/sumvive.html : SumVive 상세
- projects/thinkisland.html : 구해줘 씽크아일랜드 상세
- projects/*.pdf : 프로젝트별 원본 페이지 PDF
- portfolio.pdf : 전체 원본 PDF
- assets/slides/*.webp : 웹용 원본 슬라이드 이미지

## GitHub Pages 배포
1. ZIP 압축을 풉니다.
2. 폴더 안의 모든 파일/폴더를 GitHub 저장소 최상단에 업로드합니다.
3. Settings → Pages → Deploy from a branch
4. main / /(root) 선택 후 Save

중요: assets, projects 폴더 구조를 그대로 유지해야 합니다.
