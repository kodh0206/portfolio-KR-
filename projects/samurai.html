PROBLEM SOLVING

문제와 선택한 구조

연속 성장 처리

반복 입력 중에는 원본 데이터와 UI 피드백만 반영하고, 입력 종료 시 파생 능력치 계산과 저장을 한 번 수행하도록 경계를 분리했습니다.

저장 요청 통합

LocalSaveType Flags와 Pending Save Loop를 사용해 여러 시스템의 저장 요청을 병합하고 저장 중 추가 요청도 유실되지 않도록 구성했습니다.

서버 동기화

로컬 저장과 Dirty 상태를 분리하고 변경된 데이터만 서버 저장 Task로 만들어 불필요한 요청을 줄였습니다.

데이터 경계

JSON 역직렬화와 런타임 타입 매핑을 로딩 경계에 모아 외부 데이터 형식이 게임 로직 전체로 퍼지지 않도록 했습니다.

최대 성장 계산

레벨별 선형 반복 O(N)을 등차수열 누적 비용 + 이진 탐색 O(log N)으로 변경하고 Unity Editor에서 10만 건 기준 평균 1,675배 단축을 측정했습니다.

남은 위험까지 구분

저장 루프 경쟁 조건, 서버 저장 중 재변경 유실 가능성, 기기 시간 의존 등 확인된 한계와 다음 개선 방향을 따로 정리했습니다.
