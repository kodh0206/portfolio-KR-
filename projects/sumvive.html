PROBLEM SOLVING

문제와 선택한 구조

규칙과 화면 책임 분리

보드·연결·정답·Fever·장애물·생존 규칙을 Unity와 분리된 영역으로 두고, 화면은 확정된 결과만 받아 표시하도록 구성했습니다.

드래그 경로 일관성

위치 정보와 BlockId를 함께 사용해 중복 선택, 되돌리기, 오래된 선택을 규칙 영역에서 일관되게 검증했습니다.

풀이 가능한 목표값

목표값을 먼저 뽑지 않고 제한 DFS + 백트래킹으로 현재 보드에서 실제 가능한 목표 후보와 풀이 경로를 함께 탐색했습니다.

탐색 상한 관리

최악 복잡도를 숨기지 않고 MaxPathLength, MaxTarget, 노드 확장 수와 가지치기를 이용해 실제 실행량을 통제했습니다.

진행 불가 복구

현재 목표 확인 → 다른 목표 탐색 → 필요할 때만 Fisher-Yates 재배치 → DFS 재검증 순서로 복구하며 검증된 보드만 공개합니다.
