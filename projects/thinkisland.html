PROBLEM SOLVING

문제와 선택한 구조

상태 조합 문제

대기·진행·종료 상태를 여러 bool 값으로 표현하면서 동시에 성립하면 안 되는 상태 조합이 만들어질 수 있는 문제를 확인했습니다.

enum 상태 흐름 통합

현재 상태를 MiniGameFlowState 하나로 제한하고, 각 상태가 화면·입력·타이머 실행 여부를 결정하도록 공통 진행 구조를 구성했습니다.

18종 공통 전환 규칙

대기 → 시작 전 안내 → 게임 진행 → 다음 게임 전환 → 종료의 흐름을 공통화하여 미니게임별 상태 판단 차이를 줄였습니다.

Coroutine 수명 관리

상태가 끝날 때 해당 상태에서 시작한 Coroutine을 중단하고 참조를 정리해 이전 상태의 타이머·화면·입력 작업이 남지 않도록 했습니다.
